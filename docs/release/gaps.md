# 发行与平台缺口

本文件如实记录 M12 中**未验证的发行与平台缺口**。本环境不具备签名权限与多平台构建链，这些门禁**未执行**，不伪造成通过。

## 未验证缺口

- **三平台（macOS/Linux/Windows）打包与安装 smoke**：仅在 macOS 本机运行 `make check`；跨平台构建与安装产物的验证未执行。
- **代码签名／公证**：无签名权限，发行签名门禁**未执行**。
- **Desktop（Electron/原生壳）打包**：未实现（承 M11 缺口）。
- **Python SDK 与分发**：未实现。
- **native 平台矩阵与真实负载基准**：未执行；无真实多平台环境。
- **依赖锁定与可复现构建**：`go.mod`／`go.sum` 已锁定 Go 依赖；跨平台可复现构建未验证。
- **升级／回滚**：未实现。

发布时若仍存在上述缺口，只发布**范围明确**的版本，不声称完整复刻。
