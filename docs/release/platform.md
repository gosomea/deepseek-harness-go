# 平台矩阵与性能基准

## 平台矩阵

| 平台 | 构建 | 测试 | 说明 |
| --- | --- | --- | --- |
| darwin/amd64 | 已验证 | `make check` 通过 | 唯一实测平台 |
| linux/amd64 | 未验证 | 未执行 | 无本机环境 |
| windows/amd64 | 未验证 | 未执行 | 无本机环境 |

跨平台行为（信号、PTY、进程树终止）**未验证**；不得据 macOS 通过声称三平台等价。

## 性能基准

`benchmarks/` 提供确定性、无网络的微基准（固定种子负载），用于观察回归，不作为线上 SLA：

```sh
go test -run '^$' -bench . -benchmem ./benchmarks/...
```

基准输入、环境（darwin/amd64，Apple 虚拟 CPU）与统计方法固定；模型网络抖动不进入必要门禁。性能数字属本机观察，未在 CI 复现。
