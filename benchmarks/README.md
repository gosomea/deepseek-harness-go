# benchmarks

## 概述

本包提供核心路径的**确定性微基准**：固定种子、无网络，使性能回归可见而不被外部延迟污染。基准输入、环境与统计方法固定；数字属本机观察，非线上 SLA。它服务于 M12.7。

读者需要 Go 的 `testing.B` 基础。

## 职责

- `BenchmarkTaskstateRebuild`：投影 100 条事件到状态。
- `BenchmarkClientDelta`：从 200 条日志构建增量。

## 使用

下面的命令运行本包的基准（无网络、固定负载）。

```sh
go test -run '^$' -bench . -benchmem ./benchmarks/...
```

## 理解实现

- **无网络**：只跑纯内存投影，避免模型延迟干扰。
- **固定负载**：事件数固定，便于比较。
